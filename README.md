# 捡漏雷达 · GitHub 版

自动汇总什么值得买上的全网好价，按价格历史给出好价评分。网页是公开的，任何人打开链接就能看，不需要登录。

- **更新**：Claude 定时任务每 6 小时读取一次什么值得买好价订阅源，把数据推送到本仓库；GitHub Actions 收到推送后自动发布到 GitHub Pages。什么值得买的订阅源会拦截普通程序（GitHub 服务器、curl 都只能拿到验证页），所以用 Claude 的网页读取工具来读。
- **网页**：https://91zymercury-ctrl.github.io/mercury135/
- **历史**：价格记录按天保存在 `data/days/`，保留 60 天，网页显示最近 30 天。

## 目录
- `scripts/update.py`：抓取、去重、合并历史、生成网页数据、目标价推送（只用 Python 标准库）
- `site/index.html`：网页（手机优先，支持深色模式）
- `.github/workflows/update.yml`：收到推送后发布网页
- `data/days/*.json`：每天的好价记录（自动提交）
- `data/watch.json`、`data/prices/*.json`：追踪清单和各平台比价记录（自动提交）

## 追踪商品（任意品类：多平台比价 + 30 天走势）
- 清单在 `data/watch.json`，每个商品对应一个什么值得买百科页（`wiki.smzdm.com/p/<编号>/`）。
- 定时任务每次运行时读取这些百科页的“全网比价”，把京东、天猫等每个平台当时的最低价存进 `data/prices/<编号>.json`（保留 60 天，网页显示 30 天）。拼多多等平台的价格来自标题匹配的好价爆料。
- 走势从开始追踪那天起积累。百科的历史价格页、慢慢买、购物党都不允许程序读取，所以没有更早的历史。
- 加商品：在网页搜索框输入商品名 →「加入追踪」（会打开 GitHub 提交页，用仓库主人账号提交，下一次更新时加入）；或者直接告诉 Claude “追踪 xxx”。
- 删商品：告诉 Claude，或运行 `python3 scripts/update.py --remove-watch <编号>`。

## 商品目录（全品类热门商品，直接能搜）
- `data/catalog/pages.json` 列出要读的什么值得买百科分类列表页（约 116 页，覆盖数码、家电、服饰、美妆、母婴、食品、运动、宠物等）。
- 定时任务每次读取最久没更新的 30 页，大约一天轮完一遍；每个商品每天记一个全网最低价（`data/catalog/prices/日期.json`），网页显示 30 天走势。
- 网页搜索时才下载 `catalog.json`。目录只有全网最低价；想看分平台价格和走势，点「加入追踪」。

## 关键词目标价提醒
目标价保存在 Claude 定时任务里，不公开。想增加或修改，直接告诉 Claude，例如“加一个提醒：固态 2TB，600 元以下”。命中时会通过 Claude App 推送到手机。目标价同时检查好价爆料和追踪商品的全网比价（比价价第一次降到目标价以下时提醒一次）。

## 手动更新
在 Claude 里让它运行一次“捡漏雷达 GitHub 更新”这个定时任务。也可以在本地运行：`python3 scripts/update.py --items-json 好价列表.json`，再提交 `data/`。

## 说明
- 价格是爆料发布时的标题价，没有在商城页面核实。下单前请点“查看爆料”，去商城确认价格。
- “已观测最低价”只代表本雷达记录到的最低价，不等于商品的真实历史最低价。
